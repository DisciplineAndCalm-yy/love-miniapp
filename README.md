# 💕 我们 · love-miniapp

一对情侣用的微信小程序：每日签到、悄悄话聊天（文字/图片/语音）、日常动态、共同博客、云养宠物、日历、纪念日、每日天气+夸夸、生理期小助手、消息中心与微信订阅提醒、亲密度与成就徽章、相册时光机（往年今日）、心情看板、回忆视频（动效+BGM）、共同待办/便签/账本，以及 7 个双人互动玩法（扭蛋机 / 默契考验 / 心愿瓶 / 掷骰子 / 真心话 / 晚安打卡 / **双人冒险**）。动态与文章支持点赞、评论盖楼回复、@对方、表情回应；签到/动态/文章支持地点标注，全站图片可在相册按地点筛选；支持主题皮肤（粉樱/星夜/奶油）+ 头像挂件。

数据走微信云开发（云数据库 + 云存储 + 云函数），**不需自己买服务器**，跟着本文档一步步点鼠标即可上线。

> 适合人群：完全没写过代码、但会用电脑和微信的小白。
> 全程约 60–90 分钟（功能变多了）。遇到任何报错先看【常见问题】。

## 1. 先搞懂这 3 件事（必看，2 分钟）

**（1）本项目只有 4 个云函数，不是 13 个。**

如果你在云开发控制台看到十几个云函数，那是之前测试留下的残留，本项目只需要这 4 个：

| 云函数名 | 作用（一句话） | 必须部署 |
|---|---|---|
| `login` | 用户打开小程序时登录、建档案 | ✅ |
| `bindCouple` | 生成邀请码、两个人绑定成情侣 | ✅ |
| `api` | 所有业务（打卡/聊天/动态/博客/宠物/纪念日/6 个互动玩法） | ✅ |
| `remindAnniversary` | 纪念日当天发微信提醒（定时任务） | 可选 |

> `api` 这一个云函数里面装了约 30 个小动作（发消息、查未读、保存动态、摇骰子、晚安打卡……），你在控制台看不到它们，它们藏在代码里——这是正常的。

**（2）小程序 = 两部分。**

- 前端（`miniprogram/` 文件夹）：手机上看到的界面。
- 云端（`cloudfunctions/` + 云数据库）：存数据、管权限的大脑。

**（3）部署顺序不能乱：** 开通云开发 → 创建集合 → 加索引 → 设权限 → 部署云函数 → 真机测试。

## 2. 准备工作：注册与安装

1. **注册微信小程序账号**：打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)，点「立即注册」→「小程序」，按提示填邮箱、身份证（个人主体免费）。
   - 注册成功后，在「开发」→「开发管理」→「开发设置」里找到 **AppID**（以 `wx` 开头的一串字符），抄下来，后面要用。
2. **安装微信开发者工具**：[官方下载页](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，选 Windows / Mac 对应版本，一路「下一步」安装。
3. **准备两个微信号**：一个你自己，一个对象（或小号），联调时要两个号互相绑定。
4. **把本项目代码下载下来**：点本仓库的 `Code` → `Download ZIP`，解压到电脑上，记住路径（比如 `D:\love-miniapp`），路径里**不要有中文和空格**。

## 3. 把代码导入开发者工具

1. 打开微信开发者工具，用你的微信扫码登录。

4. 顶部工具栏把「基础库」版本选到 **3.x 最新版**（右上角「详情」→「本地设置」里可切换）。

## 4. 开通云开发并拿到环境 ID

1. 开发者工具左侧工具栏点「云开发」按钮（云朵图标），按提示开通。

3. 回到开发者工具，打开文件 `miniprogram/app.js`，第一行附近找到：

   ```js
   envId: 'cloud1-6gmcszx1cf01cffb',
   ```

   把引号里的内容替换成你自己的环境 ID，保存（Ctrl+S）。

   > 环境 ID 必须全项目一致。云函数里用的是动态环境，一般不用改。

## 6. 给集合加上索引（照抄即可）

> 索引 = 查数据的目录。不加也能跑，但人一多就变慢；带 ✅ 唯一的还能防重复数据。

1. 在数据库里点进一个集合 → 顶部切到「索引管理」→ 点「添加索引」。
2. 照下表逐个添加（字段名**区分大小写**，`_openid` 前面有下划线，别漏）：

| 集合 | 索引字段（都是升序，除非注明） | 唯一 |
|---|---|---|
| `couples` | `inviteCode` | ✅ 唯一 |
| `checkins` | `coupleId` + `dateKey` + `_openid` | ✅ 唯一 |
| `checkins` | `coupleId` + `dateKey` | 普通 |
| `posts` | `coupleId` + `createdAt`（降序） | 普通 |
| `anniversaries` | `coupleId` + `date` | 普通 |
| `moments` | `coupleId` + `createdAt`（降序） | 普通 |
| `pets` | `coupleId` | 普通 |
| `chats` | `coupleId` + `createdAt`（降序） | 普通 |
| `chatReads` | `coupleId` + `_openid` | ✅ 唯一 |
| `draws` | `coupleId` + `createdAt`（降序） | 普通 |
| `quiz` | `coupleId` + `round` | 普通 |
| `wishes` | `coupleId` + `createdAt`（降序） | 普通 |
| `dices` | `coupleId` + `createdAt`（降序） | 普通 |
| `cards` | `coupleId` + `createdAt`（降序） | 普通 |
| `nights` | `coupleId` + `dateKey` | 普通 |
| `adventures` | `coupleId` | 普通 |
| `interactions` | `coupleId` + `targetType` + `targetId` | 普通 |
| `interactions` | `coupleId` + `createdAt`（降序） | 普通 |
| `todos` | `coupleId` + `createdAt`（降序） | 普通 |
| `notes` | `coupleId` + `createdAt`（降序） | 普通 |
| `ledgers` | `coupleId` + `createdAt`（降序） | 普通 |
| `capsules` | `coupleId` | 普通 |

3. 添加索引时弹窗里：「索引名称」不用改（自动生成），「索引属性」按上表选「唯一」或「非唯一」，字段都选升序（`createdAt` 那个选降序）。
4. 加完等状态变成「正常」（创建中要等几十秒）。

> 完整清单也在 `database/indexes.json` 里备查；权限规则参考 `database/rules.wechat.json`。

## 7. 设置数据库权限规则

> 原则：小程序端**只读**，所有写入都走云函数（云函数会校验“是不是情侣本人”），这样别人扒了你的代码也偷不走、改不了数据。

1. 云开发控制台 → 数据库 → 每个集合 →「权限设置」，按下面配置：

| 集合 | 读 | 写 |
|---|---|---|
| `users` | 仅创建者可读（`doc._openid == auth.openid`） | 仅云函数（关闭客户端写） |
| `couples` | 成员可读（`doc.memberOpenids` 包含自己） | 仅云函数 |
| 其余 19 个集合（`checkins` / `posts` / `anniversaries` / `moments` / `pets` / `chats` / `chatReads` / `draws` / `quiz` / `wishes` / `dices` / `cards` / `nights` / `adventures` / `interactions` / `todos` / `notes` / `ledgers` / `capsules`） | 情侣成员可读（查所属 `couples` 文档的 `memberOpenids`） | 仅云函数 |

2. 如果控制台提供「自定义安全规则」编辑框，把 `database/rules.wechat.json` 的内容整体粘进去即可（推荐，防手滑）。
3. **云函数也要授权**：云开发控制台 → 「云函数」→ 每个函数的「权限设置」→ 允许访问数据库和云存储（默认一般已允许）。

## 8. 部署 4 个云函数（核心步骤）

1. 回到开发者工具，确认左下角「云开发」显示已连接你的环境。
2. 在左侧文件树里找到 `cloudfunctions/`，**逐个**右键 → **「上传并部署：云端安装依赖」**：
   - `cloudfunctions/login`
   - `cloudfunctions/bindCouple`
   - `cloudfunctions/api`（最大，上传要 1–3 分钟，看到“上传成功”才算完）
   - `cloudfunctions/remindAnniversary`（可选，但建议一起传）
3. 传完后去云开发控制台 → 「云函数」→ 应该能看到这 4 个函数，且「最近更新」是刚刚。
4. 点每个函数 → 「测试」空跑一次（`api` 不用测，测 `login` 有返回 `openid` 即正常）。

> 如果上传时提示 `package.json` 相关错误：右键该函数目录 → 「在外部终端打开」→ 执行 `npm install` 后再上传；或直接用「云端安装依赖」选项（已包含此步）。

## 9. 设置云存储权限（发图要用）

聊天、动态、博客、签到都要发图片，图片存在云存储的 `love/` 目录下。

## 10. 配置纪念日提醒（可选，不配也能用）

1. 去 [mp.weixin.qq.com](https://mp.weixin.qq.com) → 「订阅消息」→ 选用「纪念日提醒」类模板（本项目已用编号 **12698** 的模板），字段：
   - `thing1`：名称
   - `time2`：时间
   - `thing3`：温馨提示
   - `thing5`：临近时间
   - `time4`：农历时间
2. 模板 ID 已填好两处（换模板时两处一起改）：
   - `miniprogram/config.js` → `anniversaryTmplId`
   - `cloudfunctions/remindAnniversary/template.js` → `templateId`
3. 重新上传 `remindAnniversary`（它自带每天 9:00 的定时触发器 `config.json`）。
4. 在云开发控制台给该函数开通「订阅消息」云调用权限。
5. 小程序里点「开启提醒」并授权一次，纪念日当天双方会收到微信提醒。

**额外：时间胶囊到期 / 待办到期的微信推送**

同一个定时函数 `remindAnniversary` 会用**同一个纪念日模板**推送「胶囊可拆」「待办到期」，由 `template.js` 里的 `enableDueReminders` 开关控制（默认 `true`）：

1. 模板 `template.js` 已配好本项目的「纪念日提醒」模板（编号 12698）与 5 个字段：`thing1`名称 / `time2`时间 / `thing3`温馨提示 / `thing5`临近时间 / `time4`农历时间。
2. 每天 9:00 扫描：到期未拆的时间胶囊、今天或已逾期未完成的待办，给**已开启提醒（`remindEnabled`）**的成员各推 1 条（每条只推一次，`lastRemindStamp` 去重）。
3. 不想推这部分就把它设为 `enableDueReminders: false`。

> `time4` 农历时间会用**真实农历**（如「农历八月十五」，内置 1900–2049 换算）；若微信该字段不接受中文会自动回退为日期，确保推送成功。

**聊天消息微信提醒（「聊天消息通知」编号 3377）**

悄悄话来了可发微信通知，模板与字段已接好：

1. `chatTmplId` 已填在 `miniprogram/config.js` 与 `cloudfunctions/api/config.js`（编号 3377）。
   - 字段：`thing1`通知类型 / `thing2`消息条数 / `thing3`消息来自 / `thing5`备注 / `time6`消息时间。
2. 在「悄悄话」页点「🔔 开启微信消息提醒」授权一次；之后对方发消息会推送（成功一次消耗一次额度，额度用完再点一次即可）。
3. `api` 云函数需开通「订阅消息」云调用权限并重新部署。

## 10.5 配置每日天气（默认零配置可用，可选升级）

天气功能已**融入每日签到页**（顶部「今日天气 + 夸夸」），首页也有入口卡。默认用免 Key 的 `wttr.in`，**开箱即用**。

升级到和风天气更稳更准，需要两样东西填到 `cloudfunctions/api/config.js`：
- `qweatherKey`：和风控制台里凭证的 **API KEY**（32 位十六进制）；
- `qweatherHost`：**专属 API Host**（形如 `abcdefg.re.qweatherapi.com`）。
  - 到 [console.qweather.com/setting](https://console.qweather.com/setting) 复制（**不是**凭证页，是左侧「设置」）。
  - 只填域名，不要带 `https://` 和末尾斜杠。
  - 它是 key 之外的第二重认证；公共域名 `devapi/api/geoapi.qweather.com` **已于 2026 起逐步停用**，新 key 用旧域名会报 `403 Invalid Host`。
- 本项目已填好可用的 key + host；换账号时记得两样一起改。填好后重新上传 `api` 云函数。key 或 host 缺失/失效时会自动回落 `wttr.in`，不影响使用。
- 定位权限：`app.json` 已声明 `scope.userLocation` 与 `requiredPrivateInfos:["getLocation"]`；拒绝定位不影响，手动填城市名即可。
- 结果按「城市 + 当天」在云函数内存缓存 30 分钟。

## 10.6 配置互动消息微信提醒（订阅消息，可选，不配也能用）

「消息中心」的站内提醒默认可用；想让 TA 收到**微信服务通知**（评论/晚安/签到等），需配一个订阅消息模板。

1. 公众平台 [mp.weixin.qq.com](https://mp.weixin.qq.com) →「功能 → 订阅消息」→「选用模板」，挑一个含「谁/内容/时间」字段的模板。本项目已适配「**新留言提醒**」模板，字段：
   - `thing1` 文章标题 / `thing2` 留言用户 / `thing3` 留言内容 / `date4` 留言时间 / `time6` 发送时间
2. 把模板 ID 填到两处（保持一致）：
   - `miniprogram/config.js` → `noticeTmplId`
   - `cloudfunctions/api/config.js` → `noticeTmplId`（或给云函数配环境变量 `NOTICE_TMPL_ID`）
3. 若你的模板字段名不同，改 `cloudfunctions/api/config.js` 的 `noticeFields`：
   ```js
   noticeFields: { title: 'thing1', user: 'thing2', content: 'thing3', date: 'date4', time: 'time6' }
   ```
4. 推送开关 `noticeEvents`（省额度：默认只开评论/晚安/签到，点赞/表情默认关）：
   ```js
   noticeEvents: { comment: true, night: true, reaction: false, like: false, checkin: true }
   ```
5. **重新部署 `api` 云函数** + 小程序重新编译。
6. 双方进「消息中心 → 订阅微信提醒 → 允许」各订阅一次，即可收到。

**体验版 / 一次性订阅注意事项：**
- 代码统一用 `miniprogramState: 'trial'`，**体验版也能正常收发**；设成 `formal` 会因正式版不存在而收不到。
- 微信是**一次性订阅**：每点一次「允许」= 可收 1 条；本项目已在 `users.noticeQuota` 里做「订阅 +1 / 成功推送 −1」估算，并在消息中心提示「还剩 N 次 / 已用完·再订阅」。
- 接收方需是**体验成员**，且已对该模板点过「允许」。
- 常见错误码：`43101` 未订阅/额度用完；`47003` 字段名或时间格式不符。

## 10.7 主题皮肤 / 地点 / 回忆视频（开箱即用）

- **主题皮肤**：个人中心 →「装扮」→ 选粉樱 / 星夜 / 奶油 + 头像挂件 → 保存。会写 `users.theme/pendant` 并同步本地，导航栏、tabBar、页面背景、首页挂件立即生效；重启后自动恢复。无需额外配置。
- **地点标注**：签到、发动态、写文章时点「📍 添加地点」地图选点；签到页、动态/文章列表与详情、日历当日、相册看图浮层都会显示 `📍 地点`。需要用户授权位置（`app.json` 已声明 `scope.userLocation` / `requiredPrivateInfos`）。
- **回忆视频**：首页 →「回忆视频」→ 照片动效轮播 + 温馨 BGM（右上角 🎵/🔇 切换）；点「🎬 合成 MP4（实验）」会用 WebGL 逐帧录制尝试导出 mp4 存相册，部分机型不支持会自动回退为「保存画面」。
  - **BGM**：把一首 mp3 放到 `miniprogram/assets/bgm.mp3` 即可（没有该文件时静默跳过，不影响其它功能）。
- **性能**：已内置并行请求、骨架屏、可爱 loading 与本地缓存（stale-while-revalidate），二次进入/切 tab 秒开；天气有 30 分钟服务端缓存。

## 14. 常见问题 FAQ

**Q1：打开小程序一片空白 / 一直转圈？**
A：按顺序查：① `app.js` 的 `envId` 是否改成自己的；② `login` 云函数是否已上传；③ 左下角云开发是否连接了正确的环境。

**Q2：点“完成签到”“发布”没反应？**
A：99% 是 `api` 云函数没部署。去重新「上传并部署：云端安装依赖」，等提示成功再试。

**Q3：对方看不到我发的照片（裂图）？**
A：两步：① 第 9 步云存储权限是否放开读；② `api` 是否重新部署（含 `getTempFileURL` 换链逻辑）。缺一步都会裂图。

**Q4：首页点“悄悄话”没反应？**
A：悄悄话是底部 tab 页面，必须用 `wx.switchTab` 跳转。代码里已经是 `switchTab`，如果你自己加了入口，记得别用 `navigateTo`。

**Q5：手机上点输入框唤不起键盘、光标一闪消失？**
A：这是父级 `:active` 位移抖动抢焦点的老坑。本项目已去掉卡片级的 `:active` 位移（只保留按钮自身缩放）。如果你自己加了带 `transform` 的 `:active` 样式套在输入框祖先上，请删掉。

**Q6：改了 WXSS 报 `error at token "*"`？**
A：微信 WXSS **不支持 `*` 通配符和 `:not()`** 选择器。把 `.card > *` 这类写法展开成具体类名逐个写。

**Q7：对方能删我的博客/动态吗？**
A：不能。页面按钮只给作者显示（`mine` 判断），云函数里也二次校验（`_openid` 比对），两道锁。能互相动的是扭蛋机/心愿瓶的「完成/实现」按钮（设计如此）、宠物喂食（共同养育）、晚安打卡（各打各的）。

**Q8：底部 tab 图标想换自己的？**
A：`miniprogram/assets/tab/` 里是 162×162 的 PNG（灰 `#9A7F82` / 粉 `#E86A7A` 两套）。直接覆盖同名文件即可；`tools/gen-tab-icons.ps1` 是生成脚本（Windows 用 PowerShell 运行）。

**Q9：想清空测试数据重来？**
A：云开发控制台 → 数据库 → 逐个集合「清空数据」。注意 `users` 清空后要重新打开小程序登录。

**Q10：新增玩法后报错“找不到集合”？**
A：新增的 6 个玩法集合（`quiz` / `wishes` / `dices` / `cards` / `nights` / `adventures`）必须手动创建 + 建索引（见第 5、6 步），然后重新部署 `api` 云函数。

**Q11：WXML 报错 `unexpected token`？**
A：WXML 插值里不要写 `(a||b)[0]`、`a?.b` 这类表达式，一律在 JS 里算好字段再绑定（参考日历页 `initial` 字段的做法）。

**Q12：首页天气卡一直显示"点我设置城市"？**
A：第一次需要授权定位或在天气页手填城市名。若授权了还不行，检查 ① `app.json` 里的 `requiredPrivateInfos` 是否包含 `getLocation`；② `api` 是否已重新部署（天气逻辑在云函数里）；③ 外网偶尔抽风，下拉刷新重试即可。

**Q13：和风天气怎么开？**
A：见「10.5 配置每日天气」。不配也能用，配了更稳。

**Q14：「我们的小事」点了没反应/报错？**
A：多为 `todos / notes / ledgers` 集合不存在。本项目已在云函数里 `db.createCollection` **自动建表**（打开页面即自动创建）；请确认已重新部署 `api` 云函数。若仍报错，页面现在会弹出具体错误文案，把内容发我定位。也可在数据库里手动确认这三个集合已出现。

**Q15：微信提醒收不到 / 报 47003？**
A：见「10.6 配置互动消息微信提醒」。检查：① 模板 ID 两处是否都填、是否重部署；② `noticeFields` 是否与模板字段名一致；③ 接收方是否体验成员且点过「允许」；④ 额度是否用完（消息中心有提示）。`47003` 多为字段名或时间格式不符（date 用 `YYYY-MM-DD`、time 用 `HH:mm`）。

**Q16：装扮里换了主题，但小程序界面没变化？**
A：① 确认已重新部署 `api`（`saveTheme`/`getThemes`）；② 装扮页点「保存我的装扮」；③ 重新编译。保存时会把主题写入 `users` 与本地并在当前页立即 `applyTheme`，返回首页应能看到导航栏/tabBar/背景/挂件变化。若只有部分页面变色，说明该页未绑定 `themeBg`，可参照首页根节点写法补上。

**Q17：选地点没反应/提示不可用？**
A：需要位置权限。确认 `app.json` 的 `requiredPrivateInfos` 含 `getLocation` 与 `chooseLocation`，用户授权后即可在地图选点；拒绝定位不影响签到/发文，只是没有地点。

**Q18：回忆视频没有声音 / 合成 MP4 失败？**
A：BGM 需要 `miniprogram/assets/bgm.mp3`（没有则静默跳过）。合成 MP4 依赖 `wx.createMediaRecorder` + WebGL，部分机型/基础库不支持会自动回退为「保存画面」，属预期行为。

## 15. 二次开发须知（给会代码的人）

- **跳转规则**：tabBar 页（首页/签到/悄悄话/日历/空间）一律 `wx.switchTab`；其余 `wx.navigateTo`。
- **WXSS 禁区**：不支持 `*`、`:not()`；伪元素做装饰必须 `pointer-events: none`；原生组件（textarea/input）在真机对层叠敏感，表单控件显式提 `z-index`。
- **鉴权铁律**：所有写操作走 `api` 云函数，函数内用 `requireCouple` + `_openid` 校验；客户端的 `mine` 判断只负责隐藏按钮，不做安全依据。
- **图片链路**：上传拿 `fileID` 存库，下发前 `cloud.getTempFileURL` 换临时链接，前端优先用 `url` 字段；头像同理（`loadMembers` 已统一换链）。
- **已读回执**：`chatReads` 按人存 `lastReadAt`，`chatUnread` 服务端计数，`markChatRead` 上报 + 回传对方已读时间。
- **数据表结构**详见 [DESIGN.md](./DESIGN.md)（基础表）+ `database/indexes.json`（全部表索引）。
- **新玩法接入模板**：前端 `pages/xxx/` 四件套 → `app.json` 注册 → 首页加入口 → `api` 加动作 → 建集合 + 索引（参考 `dice` 最简实现）。
- **分包结构**：`pkgFun/` 是子包（`subPackages`），存放扭蛋/默契/心愿/骰子/真心话/晚安/冒险 7 个玩法页。子包内页面 `require` 工具要多一层 `../../../utils/`；从主包跳子包用 `wx.navigateTo({ url: '/pkgFun/pages/xxx/index' })`。
